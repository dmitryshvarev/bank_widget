# Проект "bank_widget"

## Описание:

Проект "bank_widget" - это приложение на Python, которое позволяет пользователю совершать финансовые действия или просматривать информацию без перехода на полноценную страницу банка.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/dmitryshvarev/bank_widget.git
```

2. Установите зависимости:
```
pip install poetry
poetry install
```
## Документация:

- отчет о покрытии кода тестированием находится в папке htmlcov в файле с названием
